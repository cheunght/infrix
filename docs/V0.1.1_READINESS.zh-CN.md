## 私有测试入口

测试源码仍在相邻的私有测试目录，共 15 个后端 Python 测试文件。此前从公开仓库直接执行 pytest 得到 `no tests ran`，原因是没有使用私有测试入口，不能据此判定测试丢失。

从公开仓库根目录执行，先将 `PRIVATE_TEST_ROOT` 设置为私有测试目录，并确保 `backend/.venv` 已安装其中的 `requirements-dev.txt`：

```bash
export PRIVATE_TEST_ROOT=/absolute/path/to/private-test-tools

DJANGO_ENV=development DB_ENGINE=sqlite PYTHONDONTWRITEBYTECODE=1 \
  INFRIX_REPO_ROOT="$PWD" \
  bash "$PRIVATE_TEST_ROOT/run-backend-tests.sh" \
  -q -p no:cacheprovider --junitxml=/tmp/infrix-backend-results.xml

INFRIX_REPO_ROOT="$PWD" bash "$PRIVATE_TEST_ROOT/run-frontend-checks.sh"
backend/.venv/bin/python scripts/installer-regression.py
```

私有测试入口通过 `INFRIX_REPO_ROOT` 和 `PYTHONPATH` 定位目标源码，不依赖固定的本机绝对路径。保存每次运行的应用 SHA、测试版本或文件摘要、运行时版本和 JUnit 结果。
