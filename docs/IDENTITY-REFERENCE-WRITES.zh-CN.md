# 身份与共有主数据写入

`identity_writes` 管理账号创建、普通编辑、批量启停、删除、管理员密码重置、本人资料与本地改密，以及数据范围替换。`identity_rules` 管理字段解析后的账号策略；固定角色及超级管理员保护仍复用 `organization_access`，不增加角色定义编辑能力。

账号编辑在账号锁内校验 `administration_revision` / `If-Match`，再复核当前角色、目录来源和保护规则。当前登录账号和超级管理员的角色、停用及删除限制保持；目录账号继续通过目录服务改密。创建时关联既有人员先锁人员，重新检查启用及未关联状态，再创建账号、绑定角色和记录审计。两个请求不能抢占同一人员。账号停用、资料编辑和删除不改写人员的资产责任关系。

密码重置在同一事务内修改密码、设置强制改密、撤销未撤销的 PAT 并记录撤销数量；不记录密码或 Token 原文。本人资料与管理员编辑共享版本，本地改密更新密码标记和当前会话。认证路由、Session/PAT 策略、Admin 只读与登录限流保留。等待账号锁期间目标被删，返回 404。账号启停逐条检查版本及保护规则，失败只回滚该条，审计保留批次标识。

范围替换先持目标账号的独占授权访问锁，再锁账号和授权记录；等待该账号已准入的非管理请求结束后，替换基本规则、附加规则及全部四类关系，最后记录审计。缺少/无效版本继续返回 `data_scope_revision_required`，过期返回 `data_scope_revision_conflict`。完整规则内取交集、规则间取并集，缺少授权保持拒绝。读取保留有效权限及中心、部门选择投影。

`reference_writes` 管理共有目录的事务、锁内复核、引用删除保护和审计，`reference_rules` 管理型号、字段/选项、字段集、人员及软件许可的业务校验。视图保留查询、字段解析和数量投影；字段序列化器及嵌套字段集写入委托相同规则与存储。覆盖人员、部门、厂商、设备类型、资产型号、字段集、字段/选项、标签、备件类别/目录和软件许可。备件创建及初始库存仍由库存领域处理；数量、单位限制、历史留存和软件实际超用口径不变。

共有资料修改同时要求对应功能能力与全局写范围。部门层级先锁既有设置单例作为协调行，再锁部门；部门导入也使用该顺序。该协调锁不修改设置或其修订号。选项修改先锁所属字段，再锁选项；字段集替换先锁字段集，再按 ID 锁当前及提交字段，重读字段的启用和必填展示规则。原引用及默认值保护保留，历史使用的字典项继续通过停用处理。

目录记录、字段集成员、版本及审计一起提交或回滚。字段集返回保存后的修订号；软件许可、备件保留原关联名称审计快照。专用字段集成员接口继续使用当前版本协议。目录导入保留独立事务和来源审计，不重复增加普通编辑审计。

前端 `useAccountEditor` 管理账号表单、角色规范化确认及保存；页面模块保留列表、批量操作、导入及 LDAP 配置。提交冻结目标、版本和表单值。校验或确认期间切换表单取消提交；迟到成功或错误不会关闭或污染新草稿。字典、部门和人员表单也使用独立序号。字典删除在确认前冻结类别和路径，切换类别取消操作，不能转而删除另一类同 ID 记录。

本批没有新增迁移，不回填旧资产归属或普通账号授权。HTTP 仍持维护准入直到事务及文件回调结束；已有服务器调用及后续后台作业须显式执行维护和当前账号授权准入。维护协调仍限单机、多 worker。目标服务器验收与生产部署另行执行。
